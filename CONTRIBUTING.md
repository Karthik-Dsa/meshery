# Contributing to Meshery 

Please do! Thank you for your help in improving Meshery! :balloon:

## 👋 New Contributors - Start Here!

If you're new to Meshery or open source:

- **📚 [Getting Started Guide](GETTING_STARTED.md)** - Comprehensive guide to understand the codebase, build locally, and make your first PR
- **⚡ [Quick Start Commands](QUICK_START_COMMANDS.md)** - Handy reference card for common development commands
- **🎯 [Good First Issues](https://github.com/issues?q=is%3Aopen+is%3Aissue+archived%3Afalse+org%3Ameshery+label%3A%22good+first+issue%22)** - Perfect issues to start with
- **💬 [Join our Slack](https://slack.meshery.io)** - Get help from the community

## 📖 Detailed Contributing Guides

Find the complete set of contributor guides at https://docs.meshery.io/project/contributing

These guides cover:
- Setting up your development environment
- Understanding Meshery's architecture
- Code style and conventions
- Testing requirements
- Specific guides for UI, Server, CLI, and Documentation contributions
